# Concerts Module - Quick Start

## Setup in 3 Easy Steps

### 1. Open phpMyAdmin

Go to: **http://localhost:8081**

Login: `root` / `root_password_123`

### 2. Run Setup Script

1. Click on `3sudest` database (left sidebar)
2. Click "SQL" tab (top)
3. Open file: `sql/setup_concerts_and_fix_encoding.sql`
4. Copy ALL content and paste in phpMyAdmin
5. Click "Go"

### 3. Test It!

**Public Page**: http://localhost:8080/concerts

**Admin Panel**: http://localhost:8080/admin/?page=concerts
